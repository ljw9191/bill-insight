# 账单管家 · 演示视频脚本

建议时长 6–7 分钟，录制 1440×900 或 1920×1080，浏览器缩放 100%。正式录制前使用无痕窗口，避免旧数据。

## 录制前检查

1. 执行 `npm run build`，确认构建通过。
2. 执行 `npm run dev`，打开 `http://127.0.0.1:5173`。
3. 准备文件：`public/samples/alipay-demo.csv`、`public/samples/wechat-ocr-demo.png`。
4. 关闭通知弹窗，清理浏览器下载目录。
5. 演示模式不会污染云端数据；最后再用本地模式展示持久化。

## 分镜

### 00:00–00:35 开场与定位

**画面**：登录页左侧品牌与标语，右侧三种入口。

**讲解**：

> 这是账单管家，一款把多源账单变成清晰财务全貌的应用。它解决四个问题：账单来源散、自动分类不准、隐私不可控、统计没有行动价值。今天我演示从一张截图和一份表格，到分类、入账、报表、规则学习的完整闭环。

**操作**：鼠标依次轻点“使用 WorkBuddy 登录”“本地独立模式”“快速体验演示数据”所在区域，不进入。

### 00:35–01:10 三种运行模式

**画面**：点击“本地独立模式”，出现设置口令页。

**讲解**：

> 系统有三种模式。云端模式使用 WorkBuddy 账号，数据按账号隔离；本地独立模式无需账号，数据用 AES-GCM 加密后写进本机 data/vault.json，换端口或重启也不会丢，可离线、可 Docker 独立部署；演示模式内置两月样例，便于快速评审。本地模式不是降级，而是正式的隐私优先方案。

**操作**：返回登录页，点击“快速体验演示数据”。

### 01:10–02:00 财务总览

**画面**：总览页，依次移动鼠标到四张指标卡、分类环图、每日柱图、洞察和最近账单。

**讲解**：

> 总览展示本月收入、支出、结余和结余率。这里的支出环比、最大支出分类和结余率洞察都由真实账单实时计算，不是静态文案。右侧最近账单能看到分类来源，底部业务闭环展示采集、解析、校正、报表、反馈五个阶段。

**操作**：切换月份一次，再切回本月。

### 02:00–03:20 文件导入与人工确认

**画面**：点击“账单导入”。

**讲解**：

> 导入支持支付宝、微信、银行常见的 CSV、XLS、XLSX。系统会自动寻找表头，兼容 UTF-8 和 GB18030，校验非法日期，跳过重复账单。先解析、后确认，不会直接写入账本。

**操作**：

1. 将 `alipay-demo.csv` 拖入上传区，或点击选择。
2. 预览出现后，指向分类、置信度和金额。
3. 修改一条分类为“人情”或“奖金”。
4. 点击“确认入账”。
5. 指向成功提示和下方批次记录。

**讲解**：

> 每一条都能修改日期、商户、金额、收支和分类。低置信度会标记“待核对”。确认后才加密入账，批次会留下总数、成功数、异常和重复数。

### 03:20–04:25 截图 OCR

**画面**：点击“截图 OCR”。

**讲解**：

> 截图识别完全在浏览器本地完成，图片不会上传。中文模型随应用发布，因此不依赖付费 OCR，也不需要首次使用下载大模型。

**操作**：

1. 上传 `wechat-ocr-demo.png`。
2. 等待本地识别，指向 OCR 原文和预览。
3. 强调金额可以人工修正，再取消或确认。

**讲解**：

> OCR 的目标不是假装 100% 准确，而是把用户从手工录入中解放出来，同时保留最后确认权。模糊图片识别失败时，还可以粘贴文本或手动录入。

### 04:25–05:20 修正反哺学习

**画面**：点击“账单明细”。

**讲解**：

> 分类不是黑盒。用户可以随时修改，修改会形成可复用的学习规则。

**操作**：

1. 选择一条账单的分类下拉框，改为另一个分类。
2. 出现 toast 后，指向“已反哺”。
3. 点击左侧“学习规则”。
4. 指向规则关键词、命中次数、权重和最近反馈。

**讲解**：

> 系统从商户中提取关键词，生成个人规则，优先级高于内置规则；同一关键词再次修正会提高权重和命中次数。后续导入时，相似账单会显示“规则命中”。这让一次修正变成长期能力，而且全过程可追踪。

### 05:20–06:10 智能月报

**画面**：点击“智能报表”。

**讲解**：

> 报表包括分类占比环图、每日收支、近六月支出趋势、自动洞察和分类排行。右上角可以分享汇总摘要，也可以导出 Excel 明细和可打印的 HTML 月报。分享只包含汇总，不包含商户和明细。

**操作**：点击“分享月报”，展示弹窗后取消；点击“导出明细”，在下载栏显示文件名。

### 06:10–06:45 安全与独立部署

**画面**：回到登录页，进入本地模式；或展示 README 中的 Docker 命令。若时间有限，使用截图 `12-file-persistence.png`。

**讲解**：

> 金额、商户、备注和 OCR 原文使用 PBKDF2 派生密钥与 AES-256-GCM 加密，云端数据库和本地数据文件都只看到密文。云端有行级安全策略，前端不传 owner。项目提供多阶段 Dockerfile 与 Node 服务，执行 `docker compose up -d --build` 即可在 8080 端口独立运行，数据保存在命名卷中。

**操作**：展示终端命令与设计文档架构图。

### 06:45–07:10 收尾

**画面**：总览页。

**讲解**：

> 账单管家的价值不是多一张流水表，而是让采集可信、分类可解释、隐私可控、报表可行动。它也诚实保留边界：OCR 需要人工确认，分类器是规则模型，平台 API 未私自接入。后续可以扩展加密备份、家庭账本和本地语义分类。谢谢观看。

## 备用演示：本地持久化

若评委要求验证“刷新不丢数据”：

1. 登录页点击“本地独立模式”。
2. 设置口令 `competition-2026`，进入。
3. 导入 5 条样例账单。
4. 关闭页面，重新启动服务并换到另一个端口。
5. 点击“本地独立模式”，输入相同口令，进入“账单导入”，批次与账单仍然存在。
6. 错误口令应提示“口令不正确”，不能进入。

## 录制注意

- 不要展示 WorkBuddy 账号个人信息或真实账单。
- 若网络慢，提前打开一次 OCR 页面，让浏览器缓存模型。
- Docker 未在本机安装时，不使用“已验证容器启动”的表述，只展示配置文件与构建命令。
- 本地模式的正式数据文件是 `data/vault.json`；演示时不要删除或覆盖它。
- 视频字幕与讲解中统一称“反馈学习/规则分类”，不要虚称“大模型训练”。
