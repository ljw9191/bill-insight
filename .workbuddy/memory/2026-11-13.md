# 2026-11-13

## 比赛项目「账单管家 Bill Insight」

- 完成 React 19 + TypeScript + Vite 应用，核心代码位于 `src/`。
- 实现 CSV/Excel 导入、本地 Tesseract OCR、规则分类、人工修正反馈学习、月度图表、XLSX/HTML 报表导出。
- 数据安全：PBKDF2 + AES-256-GCM；本地模式由 Node 同源 API 将密文原子写入 `data/vault.json`（保留 `.bak`），不再依赖 IndexedDB 或浏览器端口；云端模式使用 WorkBuddy 云数据库 5 张表及 owner RLS。
- 支持三种入口：WorkBuddy 账号云端模式、本地文件加密保险箱、免登录演示模式。
- 部署：多阶段 Dockerfile + Node 服务，数据保存到命名卷 `bill_insight_data`，静态入口 `dist/index.html`，中文 OCR 模型在 `public/tessdata/`。
- OCR 针对微信账单列表增加专用版式：图片先灰度增强并二值化，Tesseract 使用单块排版，逐行识别带正负号金额、关联日期、过滤汇总行；真实 1280×2774 账单列表一次识别 9 条，日期/商户/金额正确；单笔支付详情同样回归通过。
- 验证：15 项 Vitest 通过；生产构建通过；Edge + Playwright 验证真实多账单 OCR、单笔 OCR、Excel/CSV 导入、修正学习、刷新/跨端口文件解锁（5 条账单保留）、密文无明文；生产依赖审计 0 漏洞。本机无 Docker，容器未实际启动验证。
- 曾遇到用户重复启动导致 Vite 自动切换 5173-5179、浏览器 IndexedDB 按端口隔离而看似丢数据。已固定默认端口、启动脚本复用已运行服务，并将本地存储改为服务端文件，从架构上消除该问题。
